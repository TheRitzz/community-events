# community-events

A **web application** to browse, filter, and join local community events.

## Features
- Browse a list of events with details
- Filter by type, date, location
- View event details in a modal
- Join an event with a form (name, age, email, contact, note)
- Responsive and dark-themed UI with icons

## Tech Stack
- HTML, CSS, JavaScript
- Font Awesome icons for UI

## Usage
1. Open `index.html` in a browser
2. Browse events, filter them, and click **Join** to submit your details
